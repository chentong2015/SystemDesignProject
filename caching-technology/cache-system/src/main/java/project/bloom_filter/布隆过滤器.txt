TODO: 布隆过滤器: 具有容错概率
一次误判则查询一次数据库，可以挡掉大部分的请求
BloomFilter底层使用bit数组实现(存放0或1，默认为0)，占用空间很小

BloomFilter是具有容错概率的集合，集合中数据无法取出
BloomFilter不能删除数据，别的数据同样受到影响，导致数据不一致
比较难以维护，数据库中的添加，则必须同步添加到布隆过滤器中 !!

TODO. BloomFilter实现原理:
1. 首先对插入的key进行hash运算(多个hash函数)，结果%数组长度 = index位置
2. 判断是否存在也使用同样的hash运算，然后判断位置结果是否都为1

容错率来源: 如果3个位置都为1，并不能说明所查询的key一定在，可能是通过别的key计算出来组成的3个1
容错率大小: 容错率由数组长度和hash函数个数共同决定，容错率越小开销越大
无法取数据: 由于没有保存原始的数据，无法取出之前用于计算的数据
